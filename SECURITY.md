# Security policy

webular fetches web pages and documents it does not control, so it treats every page, file, and URL as hostile input.

## Supported versions

Security fixes go only into the most recent release published on npm.

## Reporting a vulnerability

Report it privately with the **Report a vulnerability** button on the repository's Security tab: <https://github.com/srinitude/webular/security/advisories/new>.

- Do not open a public issue for a vulnerability.
- Include the command, the input that triggers the problem, and what you expected to happen.
