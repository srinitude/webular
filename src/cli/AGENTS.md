# src/cli/AGENTS.md

Rules for the launcher and router, under [src/AGENTS.md](../AGENTS.md).

## What lives here

- `route.ts` and `dispatch.ts` turn `webular <command>` into the command's own process. `dispatch-table.ts` is the generated list they read.
- `commands.ts` is the one list of commands and their one-line help. Help text and the router both read it.
- `run.ts` runs a Mastra workflow for a command, then prints the result and sets the exit code. `render.ts` holds one small human renderer per command.
- `help.ts` and `style.ts` shape terminal text: wrap, color, error labels, and "did you mean".
- `launch.ts` picks what runs: the native build, else Bun on `dist`, else Bun on `src`.
- `exit-codes.ts` is the one source of exit codes.

## Rules

- The CLI routes only. It never imports command code, so each command runs in its own process.
- `dispatch-table.ts` is generated by `scripts/gen-dispatch.ts`. Never edit it. Change `mise.toml`, then run `mise run build`.
- Adding a command needs an entry in `commands.ts` and a renderer in `render.ts`. A missing renderer is a compile error.
- Machine data goes to stdout and notes go to stderr. Color only decorates, so the words must carry the meaning.
- The `--json` shape is the agent contract. Ask first before you change it.
