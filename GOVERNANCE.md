# Governance

webular has one maintainer, [@srinitude](https://github.com/srinitude). The maintainer owns the roadmap, reviews and merges every pull request, and cuts every release.

## How decisions are made

- Most changes are decided in the pull request. The maintainer merges when the checks in [CONTRIBUTING.md](CONTRIBUTING.md) pass and the change fits the project.
- Large or breaking changes start as an issue. Anyone can comment. The maintainer decides after the discussion and writes the reason in the issue.
- Changes to exit codes, `--json` shapes, and MCP tool names follow [docs/agent-contract.md](docs/agent-contract.md).
- The [Code of Conduct](CODE_OF_CONDUCT.md) applies to every decision.

## Becoming a maintainer

The maintainer can invite contributors who send steady, high-quality changes, review other people's work, and follow the Code of Conduct. A maintainer gets write access and an entry in [.github/CODEOWNERS](.github/CODEOWNERS). A maintainer can step down by saying so in an issue.

## Changing this page

Propose changes by pull request. The maintainer decides.
