# plugins/webular/skills/webular-research/references/AGENTS.md

This folder holds the detail the webular-research skill loads on demand. The skill rules are in [AGENTS.md](../AGENTS.md).

## What lives here

- `plugins/webular/skills/webular-research/references/tools.md` is a table of the webular tools. Each row gives a section, when to use it, when not to, and related sections.

## Rules

- Every row links a heading in the same file.

## Checks

- `mise run plugin:check-links` resolves those anchors.
