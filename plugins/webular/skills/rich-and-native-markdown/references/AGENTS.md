# plugins/webular/skills/rich-and-native-markdown/references/AGENTS.md

This folder holds the guides the rich-and-native-markdown skill loads on demand. The skill rules are in [AGENTS.md](../AGENTS.md).

## What lives here

- `plugins/webular/skills/rich-and-native-markdown/references/catalog.md` lists the Markdown forms and when to use each.
- `plugins/webular/skills/rich-and-native-markdown/references/checks.md` covers file checks and the limits of their evidence.
- `plugins/webular/skills/rich-and-native-markdown/references/structure.md` covers context, structure, disclosure, and readability.

## Rules

- Each guide opens with a table of sections. Every row links a heading in the same file.

## Checks

- `mise run plugin:check-links` resolves those anchors.
