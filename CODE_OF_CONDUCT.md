# Code of Conduct

webular follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in every space the project runs, including issues, pull requests, and discussions. It also applies when someone represents the project in public.

## Reporting

To report a violation, send a private report to [@srinitude](https://github.com/srinitude). Use the **Report a vulnerability** form on the [Security tab](https://github.com/srinitude/webular/security/advisories/new), and say it is a conduct report. The maintainer reviews every report, keeps the reporter's identity private, and applies the enforcement guidelines in the Covenant.
