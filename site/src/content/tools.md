# MCP tools

`webular mcp` has 24 tools. The table marks which ones only read and which ones reach the web.

The tools are grouped by job: Find, Read, Think, Watch and act, Tools and setup, Flow machines, and Low-level HTML. Each tool carries `readOnlyHint`, plus `openWorldHint` on a tool that reaches the web. When a tool has no `destructiveHint`, the table shows "not set", not "no".
