## Rules

- Each file is both a page body and its .md twin, so it must read well on its own.
- Copy comes word for word from the content plan. A gated claim stays out until its gate passes.
- No page file may share a name with AGENTS.md or CLAUDE.md in any letter case, because a case-blind disk would merge them. The agents page is [for-agents.md](for-agents.md) for that reason.
