# site/design/AGENTS.md

The design tokens for the site, under [site/AGENTS.md](../AGENTS.md).

## What lives here

- [tokens.json](tokens.json) holds the colors and other design tokens in the DTCG format. The script [tokens-css.ts](../scripts/tokens-css.ts) turns it into [tokens.css](../src/tokens.css).

## Rules

- Change a token here, then rerun the script. Never edit [tokens.css](../src/tokens.css) by hand.
