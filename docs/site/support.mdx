This page has no command to run, because it is a list of links. To check your own setup, see [Troubleshooting](/troubleshooting).

Read these docs first. To fix something yourself, see [Contributing](/contributing).

## Discussions

For questions and ideas, ask in [GitHub Discussions](https://github.com/srinitude/webular/discussions).

## Issues

For bugs and feature requests, open an [issue](https://github.com/srinitude/webular/issues). Include the command, the input, and what you expected.

## Security

Do not post security problems in public. To report one privately, follow [Security and privacy](/security).

## Code of conduct

webular follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in every space the project runs, including issues, pull requests, and discussions. To report a violation, read the [Code of Conduct](https://github.com/srinitude/webular/blob/main/CODE_OF_CONDUCT.md).

## License and citation

webular is open source under Apache-2.0 © Kiren Srinivasan. See [LICENSE](https://github.com/srinitude/webular/blob/main/LICENSE).

To cite webular, use the metadata in [CITATION.cff](https://github.com/srinitude/webular/blob/main/CITATION.cff).
